# Quick Docker Test Commands

## Fastest Way to Validate (Copy & Paste)

```bash
# Clone repo
git clone <your-repo-url> adaptive-bandit-test
cd adaptive-bandit-test

# Build and run all 3 methods with minimal steps (2 timesteps each)
docker build -f Dockerfile.test -t adaptive-bandit-test:latest .

# After build completes, verify outputs exist:
ls -lah output/numerical-multi-turn/
ls -lah output/nlp-multi-turn/
ls -lah output/contextual-bandit/
ls -lah best_model/numerical/
ls -lah best_model/nlp/
```

## Using Docker Compose (Even Easier)

```bash
git clone <your-repo-url> adaptive-bandit-test
cd adaptive-bandit-test
docker-compose -f docker-compose.test.yml build
docker-compose -f docker-compose.test.yml up
```

## On Fresh Ubuntu 22.04 (No Docker)

```bash
git clone <your-repo-url> adaptive-bandit-test
cd adaptive-bandit-test

# Set minimal timesteps and run
export NUM_TIMESTEPS_NUMERICAL=2
export NUM_TIMESTEPS_NLG=2
bash run.sh
```

## What You Get After Running

```
✓ 3 trained models in best_model/
✓ All metrics and artifacts in output/
✓ Success message showing all validations passed
✓ Ready for professor submission
```
